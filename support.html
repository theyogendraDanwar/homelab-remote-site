Common help

  • Link servers in Settings → Configuration with the host URL and API key from your service.
  • Use the same Wi‑Fi or a VPN (for example Tailscale) so your phone can reach your Homelab.
  • PIN / Face ID is set under Settings → Security.
  • Optional tips: Google Pay QR in India; App Store tips elsewhere. Tips unlock no features.
